# Railway station sanitation simulator

Integrated planning model for toilets, staffing, water storage (GLR/OHT), pumping, sewage equalization, STP, electricity, capital expenditure and operating expenditure.

## Run

```bash
pip install -r railway-station-sanitation/requirements.txt
streamlit run railway-station-sanitation/app.py
```

The model is illustrative, not a tender-ready BOQ. See technical paper and dataset on OneDrive: https://onedrive.live.com?cid=BDD18D98B3B583D5&id=BDD18D98B3B583D5!s9b8d71929b054fe397b17ff5d1075008
